# pphomework4

作业四进阶实现：启动网页演示：

```bash
python web_demo.py
```

然后访问 http://127.0.0.1:8088/。

## 满分要求覆盖

### 要求2：基础功能

- 手动双边滤波：直接在邻域中计算空间高斯权重与像素域高斯权重，不调用 OpenCV 双边滤波函数。
- 手动导向滤波：以灰度图为引导，按局部线性模型求解系数，并将系数应用到每个颜色通道。
- 锐化对比：分别对手动双边滤波和手动导向滤波结果做细节增强，并并排展示。

### 进阶要求

- 快速导向滤波：使用积分图手动实现盒式均值滤波，在缩小图像上估计导向滤波系数，再上采样系数并重建原图。
- 手动 BM3D：实现相似块搜索、块组堆叠、二阶二维 DCT 变换、硬阈值协同滤波、Wiener 阶段和重叠块加权聚合。
- 创意功能：快速导向滤波去噪与反遮罩细节增强组合，可调节增强强度。

## 不使用传统方法要求1

本作业的界面不提供 `cv2.bilateralFilter` 和 `cv2.fastNlMeansDenoisingColored` 选项，避免与需要同时完成要求2的进阶路径冲突。

## 参数说明

- 双边滤波强度控制像素颜色差异容忍度，空间邻域半径控制局部搜索范围。
- 导向滤波 ε 控制局部回归正则化；窗口半径越大，平滑越强。
- BM3D 噪声标准差按图像灰度范围 0–255 设置。
- 大图或小步长会增加 BM3D 计算时间，建议先缩小图片或使用较小噪声参数测试。
