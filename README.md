# pphomework4

作业4：图像去噪与锐化。启动网页演示：

```bash
python web_demo.py
```

然后访问 http://127.0.0.1:8088/。

## 已实现功能

- **OpenCV 基线**：`cv2.bilateralFilter` 双边滤波与彩色图像 `cv2.fastNlMeansDenoisingColored` NLM 去噪（灰度图对应使用 `fastNlMeansDenoising`）。
- **手动双边滤波**：逐邻域计算空间高斯权重与像素值域高斯权重。
- **手动导向滤波**：按局部线性模型求解系数，使用积分图实现盒式均值。
- **快速导向滤波**：先在缩小图像上估计局部线性系数，再上采样系数并在原分辨率重建，降低计算量。
- **手动 BM3D**：块匹配构造相似图像块组，采用组维度与空间维度的 DCT 变换，依次执行硬阈值协同滤波和 Wiener 协同滤波，最后对重叠块加权聚合。此实现面向课程演示，速度和画质不等同于高度优化的 BM3D 库实现。
- **锐化对比**：并排展示手动双边滤波与手动导向滤波结果的反遮罩锐化。
- **创意功能**：快速导向滤波去噪后进行可调节的细节增强。

BM3D 的 `滤波强度 / 噪声标准差` 参数按输入噪声的近似标准差（0–255 灰度范围）设置。BM3D 需要对图像块进行搜索，处理大图会明显慢于其它方法；建议先用较小图片验证参数效果。
